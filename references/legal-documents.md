# 用户协议、隐私政策与同意记录

Luz Dev 负责把协议做成系统功能：文本版本化、在正确的位置展示、取得并记录同意、变更后重新同意、提供撤回与注销。协议正文由模板起草，**上线前须由商户确认并建议律师审核**；Luz Dev 不替商户作法律判断。
模板：`assets/legal/`。参考代码设计：本篇 §4。相关规范：LEGAL-*、PII-*、FACE-002、MBR-002、MKT-004、PII-003。

## 1. 文档清单

| 文档 | 何时需要 | 展示位置 | 同意方式 |
|---|---|---|---|
| 用户服务协议 | 所有项目 | 登录 / 注册页、个人中心 | 首次登录时主动勾选（不得默认勾选） |
| 隐私政策 | 收集个人信息即需要 | 登录页、个人中心、设置 | 同上；与用户协议可同屏但分别可读 |
| 小程序用户隐私保护指引 | 小程序使用隐私接口 | 在小程序后台填写；调用隐私接口前按官方隐私协议开发指南弹出 | 平台机制（PII-003） |
| 人脸信息处理单独同意书 | 采集人脸 | 人脸录入页 | 单独同意，不与其他条款捆绑；可撤回（FACE-002） |
| 储值卡 / 会员卡协议 | 售卖预付卡、次卡、年卡 | 购买页 | 购买前确认；展示冷静期、退费、转让规则（MBR-002） |
| 退款与售后规则 | 有收款 | 商品详情、下单页、售后申请页 | 展示即可，下单时提示 |
| 活动 / 抽奖规则 | 营销活动 | 活动页 | 展示；开始后不可变更（MKT-004） |
| 第三方 SDK / 共享清单 | 接入第三方服务处理个人信息 | 隐私政策附件 | 随隐私政策 |
| 账号注销说明 | 所有有账号的项目 | 设置 → 注销 | 注销前确认后果（PII-004） |
| 未成年人规则 | 可能有不满 14 周岁用户 | 隐私政策专章 | 监护人同意（FACE-002） |

## 2. 隐私政策必须写清的内容

按《个人信息保护法》对告知事项的要求，至少包括：处理者名称与联系方式；处理的个人信息种类、目的、方式、保存期限；敏感个人信息（人脸、身份证、行踪等）的必要性与影响；委托处理、共享与第三方清单；个人行使查阅、复制、更正、删除、撤回同意、注销的方式；安全措施；未成年人保护；变更通知方式；生效日期与版本号。内容必须与系统实际收集的字段一致（PII-001），方案的数据模型表标注每个个人信息字段。

## 3. 同意的实现

| 要求 | 做法 |
|---|---|
| 主动同意 | 复选框默认不勾选；未同意不能继续需要该信息的功能，但可以浏览不需要个人信息的内容 |
| 可追溯 | 记录：用户、文档类型、版本号、文本哈希、同意时间、渠道（小程序 / 后台代录）、IP 或设备标识（脱敏） |
| 版本化 | 文档表保存每个版本的完整文本与生效时间；页面展示当前生效版本 |
| 变更重新同意 | 实质性变更后，用户下次进入时展示变更摘要并重新同意；未重新同意的不再处理新增目的的数据 |
| 撤回 | 提供撤回入口（如人脸、营销推送）；撤回后停止处理并删除相应数据 |
| 后台代录 | 门店代客录入时，同意必须由用户本人在其设备上完成或保留书面证据 |

## 4. 数据模型与接口（参考）

| 表 | 字段 |
|---|---|
| `legal_documents` | `id`、`kind`（terms / privacy / face_consent / prepaid / refund / activity）、`version`、`title`、`content`（Markdown）、`content_sha256`、`effective_at`、`status`（draft / published / retired） |
| `user_consents` | `id`、`user_id`、`document_id`、`version`、`content_sha256`、`accepted_at`、`channel`、`client_hint`（脱敏）、`withdrawn_at` |

| 接口 | 说明 |
|---|---|
| `GET /api/v1/app/legal/{kind}` | 当前生效版本 |
| `GET /api/v1/app/legal/pending` | 当前用户尚未同意的必需文档 |
| `POST /api/v1/app/legal/consents` | 提交同意（文档 ID + 版本 + 哈希，服务端校验为当前版本） |
| `POST /api/v1/app/legal/consents/{id}/withdraw` | 撤回 |
| `POST /api/v1/admin/legal/documents` · `/publish` | 新建版本、发布（权限 `legal:publish`，写审计） |

发布新版本只新增记录，不修改已发布文本；同意记录只追加。

## 5. 上线前检查

- 所有适用文档已发布且有版本号；小程序后台隐私保护指引已填写且与隐私政策一致。
- 登录、人脸录入、购买储值卡等入口展示正确文档并记录同意。
- 注销与撤回流程走通，删除覆盖第三方。
- 商户已确认文本；建议的律师审核已完成或已记录为商户决定。
