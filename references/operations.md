# 运维与上线

Luz Dev 负责从开发到上线的全流程。本篇覆盖环境、部署、域名与证书、小程序发布、监控、备份、回滚与上线检查；资质与备案见 `compliance.md`，协议见 `legal-documents.md`。
模板：`assets/deploy/`（Docker Compose、Nginx、环境变量示例、备份脚本、上线检查表）。相关规范：REL-*、OPS-*、DATA-002、DATA-003、OBS-*、SECRET-*、PROC-004。

## 1. 环境

| 环境 | 用途 | 规则 |
|---|---|---|
| 本地 | 开发 | 依赖用容器启动；测试数据可清理 |
| 测试 / 预发 | 联调、验收、演练 | 与生产同构（同版本数据库、同配置结构）；微信支付使用独立商户配置或小额真实验证；数据脱敏 |
| 生产 | 正式 | 只能通过发布流程变更；秘密只在密钥服务或受限文件 |

每个环境一份配置清单（`config/<env>.md`）：配置项、用途、获取方式、验证方法；秘密只写存放位置（PROC-004、SECRET-001）。

## 2. 部署默认方案

| 层 | 默认 | 说明 |
|---|---|---|
| 服务器 | 云服务器（1–2 台起步）+ 云数据库或自建 PostgreSQL | 小程序后端服务器域名必须完成 ICP 备案（compliance.md） |
| 运行 | Docker Compose：`api`、`worker`（发件箱与定时任务）、`postgres`、`redis`、`nginx` | 生产配置见 `assets/deploy/docker-compose.prod.yml` |
| 入口 | Nginx：HTTPS（TLS 1.2+）、HTTP 跳转 HTTPS、请求体大小限制、安全响应头、反向代理到 api | 证书自动续期并在到期前告警 |
| 迁移 | 发布时先执行 Alembic 迁移，再滚动重启 api | 破坏性变更分两次发布（先兼容，再清理） |
| 管理后台 | 静态资源由 Nginx 提供，独立子域名；可限制来源 IP | 后台与用户端接口分开路由前缀 |
| 小程序 | 微信开发者工具上传 → 体验版验收 → 提交审核 → 发布 | 服务器域名在小程序后台配置为 HTTPS 合法域名 |

## 3. 发布流程

```text
合并到主分支 → CI：测试、安全扫描、构建镜像（打版本号）
 → 预发部署 → 迁移演练 → 冒烟测试与关键流程（下单、支付、退款）
 → 生产：备份数据库 → 迁移 → 发布 api / worker → 健康检查 → 冒烟测试
 → 观察告警 30 分钟 → 发布小程序体验版验收 → 提交审核 → 发布
```

回滚：镜像回到上一版本；数据库迁移写明回滚或前向修复；小程序可在后台回退到上一版本（以官方说明为准）。每次发布写发布记录：版本、变更、迁移、执行人、结果。

## 4. 监控与告警

| 类别 | 指标 | 告警 |
|---|---|---|
| 可用性 | 健康检查、接口错误率、P95 延迟 | 连续失败、错误率超阈值 |
| 业务 | 下单数、支付成功率、支付确认中积压、退款异常、对账差异 | 偏离基线（OBS-003） |
| 任务 | 发件箱积压与死信、关单任务、对账任务 | 积压或失败 |
| 资源 | CPU、内存、磁盘、数据库连接、慢查询 | 超阈值 |
| 证书与域名 | 证书剩余天数、域名到期 | 30 天内到期 |
| 安全 | 登录失败激增、回调验签失败、异常导出 | 激增 |

日志集中存储并带 trace_id（OBS-001），保留期限写入方案。

## 5. 备份与恢复

| 对象 | 频率 | 保存 |
|---|---|---|
| 数据库 | 每日全量 + 持续 WAL / 时间点恢复（云数据库自带则启用） | 异地、加密、至少 7–30 天 |
| 上传文件 | 对象存储开启版本或跨区域复制 | — |
| 配置与证书 | 变更即备份 | 受限访问 |

每季度做一次恢复演练并记录耗时（DATA-003）。

## 6. 安全加固

- 服务器：SSH 仅密钥登录、禁止 root 密码登录、安全组只开放 80/443 与受限的管理端口；系统自动安全更新。
- 数据库、Redis 不暴露公网。
- 管理后台：登录限速与锁定、可选来源 IP 白名单、操作审计（AUTH-005、OBS-002）。
- 微信支付回调地址公网可达；防火墙策略允许回调到达（PAY-013）。

## 7. 上线检查表

上线前逐项确认并在方案“上线与合规”章节记录证据：

| 类别 | 检查项 |
|---|---|
| 资质 | 主体资质、ICP 备案（网站与小程序）、小程序类目、支付商户号与 appid 绑定、特殊能力资质（compliance.md） |
| 协议 | 用户协议、隐私政策、小程序隐私保护指引、专项同意（人脸、储值）已上线且有同意记录（legal-documents.md） |
| 配置 | 生产配置与秘密到位；联调密钥已移除；服务器域名已配置 |
| 数据 | 迁移在预发演练通过；初始化数据（管理员、字典、门店）就绪；首次登录强制改密 |
| 功能 | 关键流程真实走通：登录、下单、支付（真实小额）、回调、查单、退款、对账 |
| 前端 | Luz System 设计绑定检查通过；关键页面与原型截图对照 |
| 运维 | 健康检查、监控告警、日志、备份与恢复演练、回滚方案 |
| 文档 | README、`config/`、发布记录、遗留问题 |
| 发布后 | 观察告警、核对首日订单与对账、用户反馈渠道 |
