# 优惠券：发放、领取、使用、核销、回退

参考代码：`backend/16-coupon/code/coupon/`（领取、锁定 lock / 解锁 unlock / 核销 confirm_use / 退回 return_coupon，测试 10 项含 20 笔订单并发抢一张券）、`backend/17-campaign/code/pricing/`（券在计价中的计算）。
相关规范：MKT-001～MKT-004、MONEY-003、RFD-004。

## 1. 模型

| 表 | 内容 |
|---|---|
| 券模板 / 批次 | 类型（满减、折扣、兑换）、面额、门槛、适用范围、有效期（固定日期或领取后 N 天）、总量、已发、每人限领、互斥组、预算 |
| 用户券 | 模板、用户、状态、生效 / 过期时间、锁定订单、核销时间 |

用户券状态：`available → locked（下单）→ used（支付成功）`；`locked → available`（取消 / 超时）；`available → expired`；`used → available | returned`（退款时按规则退回）。

## 2. 规则

| 环节 | 做法 |
|---|---|
| 领取 | 条件更新扣减批次剩余（`issued < total`）；每人限领用唯一约束或条件计数；领取接口限流（MKT-001） |
| 发放 | 系统发放（注册礼、支付后返券）通过发件箱，以业务单号幂等 |
| 选券 | 试算时服务端计算可用券并给出不可用原因；默认推荐优惠最大的券 |
| 使用 | 下单事务内锁定券（`available → locked`，条件更新），与订单绑定 |
| 核销 | 支付成功事件中 `locked → used` |
| 回退 | 取消 / 超时解锁；退款后是否退回、过期券是否补发、部分退款是否退回，由商户确认（RFD-004） |
| 过期 | 定时任务批量置为过期，写日志 |
| 成本 | 记录券成本承担方（平台、商户）用于对账 |

## 3. 测试清单

- 并发领取不超过总量和每人限领。
- 同一张券并发用于两笔订单只成功一笔；取消后券恢复可用。
- 过期券不能使用；不满足门槛给出原因。
- 退款后按配置退回或不退回。
