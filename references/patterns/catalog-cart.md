# 商品、SKU、价格与购物车

相关：inventory.md、pricing.md、order.md、purchase-rules.md。相关规范：MONEY-001、MONEY-002、ORDER-005。

## 1. 商品模型

| 表 | 内容 | 说明 |
|---|---|---|
| SPU 商品 | 名称、分类、详情、图片、上下架、销售模式（实物 / 服务 / 卡券 / 课程） | 展示单位 |
| 规格 | 规格项（颜色、尺码 / 时长、次数）与规格值 | 生成 SKU |
| SKU | SPU、规格组合、价格（分）、划线价、库存、编码、状态 | 交易单位；库存与价格挂在 SKU 上 |
| 门店价 / 会员价 | SKU + 门店 / 等级 → 价格 | 按需；价格解析顺序写入方案 |

| 规则 | 做法 |
|---|---|
| 改价 | 只影响之后的订单；历史订单用快照；改价写审计 |
| 上下架 | 下架后不可加购、不可下单；已在购物车的标记失效 |
| 删除 | 软删除；有订单引用的 SKU 不物理删除 |
| 服务类商品 | 年卡、次卡、课程包：购买后生成权益（次数、有效期），与预约、核销关联 |

## 2. 购物车

| 规则 | 做法 |
|---|---|
| 存储 | 登录用户存数据库（或 Redis + 定期落库）；未登录存本地，登录后合并（同 SKU 数量相加，不超过限购） |
| 价格 | 购物车不存价格，每次展示与结算按当前价格计算，价格变化时提示 |
| 失效 | 下架、售罄、规格删除的条目单独分组显示，不能结算 |
| 数量 | 不超过库存与购买规则的剩余（purchase-rules.md）；库存与名额都不在加购时扣减 |
| 结算 | 勾选条目进入试算（order.md），下单成功后删除已下单条目 |

## 3. 测试清单

- 改价后历史订单金额不变；下架商品不能下单。
- 登录合并购物车数量正确、不超过限购。
- 失效条目不能结算；结算价格以服务端为准。
