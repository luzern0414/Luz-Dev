# Project implementation template

Copy this directory's files into the generated project's `docs/` folder. The project should also contain the approved `HANDOFF.json` and only the applications and services it needs.

Use `IMPLEMENTATION.md` for architecture and decisions, `PLAN.md` for executable slices, and `QUALITY.md` for evidence. Keep secrets out of these files.
