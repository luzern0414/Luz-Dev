# 功能逻辑目录与可视化编辑模板

## 摘要

建立 canonical JSON、标准库构建器、Luz Design Admin v2 独立 HTML 工作台和包级漂移校验，让人与后续 Agent 共用 8 个模块、26 个功能的后端逻辑基线。

## 决策与做法

- 以 references/function-catalog.json 作为唯一结构化事实源；构建器安全嵌入数据并生成 references/function-catalog.html。
- 浏览器编辑只保存本地草稿；正式维护必须导出 JSON、替换 canonical 文件、运行构建器并再次校验。
- 页面使用 Luz Design Admin v2 的 240/72px 侧栏、64px 顶栏、13px 表格、8/12px 圆角及 ai-agent 语义令牌，并保持无外部依赖。

## 失败尝试与教训

- 首次运行集成测试时正式 HTML 尚未生成，只能通过构建器生成后完成 canonical JSON 与页面内嵌数据的一致性验证。
